# 📋 業務日報アプリ - 開発コンテキスト & 仕様履歴

このファイルは、本プロジェクト（業務日報アプリ）の開発経緯、システムの仕組み、およびこれまでにカスタマイズされた仕様を記録し、今後のAI開発アシスタントがコンテキストとして参照できるようにするためのものです。

---

## 🌐 システム構成と実動の仕組み

アプリは以下の3つのシステムが連携して稼働しています。

1. **フロントエンド (UI/画面)**
   - HTML / Vanilla CSS / Vanilla JavaScript (一部jQuery風のセレクタヘルパー使用)
   - スマートフォンでの操作を第一に考えたレスポンシブなダークモードWebアプリ。
2. **バックエンド (Webサーバー)**
   - Node.js + Express
   - **Render** (無料プラン) 上で稼働。
   - 日本時間 (JST/UTC+9) でのデータ記録に対応するタイムゾーン補正機能。
3. **データベース**
   - **Turso** (SQLite互換の分散クラウドデータベース、無料プラン)
   - `work_records` (日報記録), `weekly_schedules` (週間スケジュール), `deadline_tasks` (期限付きタスク) のテーブルでデータを永続化。

### 🚀 デプロイと更新の流れ
1. ローカルでの修正完了後、GitHub用トークンを使用してデプロイスクリプトを実行。
   ```bash
   node deploy-note-update.js <GITHUB_TOKEN>
   ```
2. スクリプトが GitHub のリポジトリへファイルを直接更新 (Push)。
3. **Render** が GitHub の更新を検知し、自動的に最新のプログラムをビルドして再起動・デプロイします。
   *(手動反映時は、Renderダッシュボードから `Manual Deploy` ➔ `Deploy latest commit` を実行)*

## 🛠️ これまでのカスタマイズ履歴 & 仕様

### 1. アプリ基本情報
- **題名**: 「醸造日報」から **「業務日報」** に変更。
- **カテゴリ追加**: 大項目「その他共通」の中の中項目として、**「運搬」** と **「その他」** を追加。
- **タイムゾーン対応**: サーバー時間 (UTC) に依存せず、タイムライン等に記録される時間が**日本時間 (JST)** と一致するように修正。

### 2. 期限付きタスク機能 (カウントダウン)
- **機能概要**: 期日と内容を入力して保存すると、トップ画面上部にカウントダウンが表示される。
- **カウントダウン設定**: 期日当日ではなく**「期日前日の日付」**を基準にカウントダウン（前日時点でほぼ完成している状態を目指すため）。
- **色分け表示**:
  - 🟢 残り4日以上：余裕あり
  - 🟡 残り3日以内：黄色表示
  - 🔴 前日または超過：赤色点滅表示 (アニメーション)
- **導線**: 「分析」ボタンを廃止し、下部メニューの3番目を **「⊕ タスク追加」ボタン** に変更。タップでタスクの追加・編集・完了・削除が行える。

### 3. スケジュール機能
- **製造日程 (旧: 週間日程)**:
  - 曜日 (月〜土) × 時間帯 (AM/PM) のグリッド形式。セルをタップして手入力。
  - **本日ハイライト**: 毎日「本日の日付」の列（ヘッダーとセル）が**アンバー色 (黄色系)** に自動でハイライトされ、今日が何日かすぐ分かるように修正。
- **仕込予定 & 濾過火入れの統合**:
  - かつて存在した「仕込予定」「濾過火入れ」の個別タブおよび行追加式のリストを廃止。
  - **「製造日程」の真下に、それぞれの週間グリッド（仕込予定、濾過火入れ）を並べて配置**。
  - 仕込・濾過グリッドは **AM/PMの区分なし (1日1マス)**。
  - セルをタップすると「仕込予定」「濾過火入れ」に対応したラベルで編集モーダルが開き、手入力が可能。
  - 保存はすべて一括で `weekly_schedules` テーブル of `schedule_data` (JSON) に統合して保存される。

### 4. 振替必要日数カウント表示
- **表示**: トップ画面左上に「振替必要日数」を配置。
- **編集**: タップすると専用の入力モーダルが開き、小数点第一位まで数値を変更・時間管理可能。
- **借金💦表記**: 数値が0未満（マイナス）になった場合、文字表記が「振替必要日数」から**「借金💦」**へ自動で切り替わる。
- **永続化**: データベースの `app_settings` テーブル（新規作成）に保存される。

### 5. 作業同行者追加・表示機能
- **概要**: 作業開始時、または後からタイムライン上の既存記録を編集する際、作業の同行者を記録できる機能。
- **従業員名トグル選択**: 同行者として定義済みの11名（「部長」「藤森」「宮澤」「工藤」「百瀬」「松倉」「野口」「志賀」「林(麗)」「野明」「高木」）をボタンのワンプッシュでトグル（複数選択）可能。
- **その他手入力**: 従業員以外の同行者を記録するための手入力欄も完備。
- **タイムライン上の表示**: 登録された同行者はタイムライン上の各カードに `👥 同行者名, ...` として一目でわかるようにバッジ風に表示。
- **永続化**: `work_records` テーブルに追加した `co_workers` カラムに保存される。
- **挙動**: 作業開始時に必ず同行者を確認・選択できるようにするため、すべての作業（サブカテゴリが0個または1個のカテゴリも含む）の開始時に確認ダイアログ（同行者/メモ）を表示。
